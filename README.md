# Orbit

Orbit manages navigation stacks, tab selection, and modal flows in SwiftUI.
Screens send route objects to a router; registered factories create the
destination views.

[API reference](https://stlarner.github.io/Orbit/api/) ·
[Usage guide](https://stlarner.github.io/Orbit/api/documentation/orbit/usageguide)

The documentation is generated by GitHub Actions from `main`. It describes
the current branch, which may include changes beyond the latest release.

## Installation

Add Orbit with Swift Package Manager and select the `Orbit` product for your
app target:

```swift
.package(url: "https://github.com/STlarner/Orbit.git", exact: "0.5.0")
```

| Requirement | Version |
|---|---|
| Swift | 6.2 or later |
| iOS | 17 or later |
| macOS | 14 or later |

Full-screen covers and tab-bar visibility policies are available on iOS.

## Setup

Define a route for each destination, register its view factory, and display
the selected root with `OrbitRootHost`. Keep an Orbit instance in each window's
root view so windows have their own navigation history.

```swift
import Orbit
import SwiftUI

nonisolated final class HomeRoute: OrbitRoute {}

nonisolated final class DetailRoute: OrbitRoute {
    let title: String

    init(title: String) {
        self.title = title
        super.init()
    }
}

@main
struct ExampleApp: App {
    var body: some Scene {
        WindowGroup { AppWindow() }
    }
}

@MainActor
struct AppWindow: View {
    @State private var orbit: Orbit

    init() {
        let orbit = Orbit()
        orbit.register(HomeRoute.self) { _ in HomeView() }
        orbit.register(DetailRoute.self) { route in
            Text(route.title).navigationTitle(route.title)
        }
        orbit.setRoot(HomeRoute())
        _orbit = State(initialValue: orbit)
    }

    var body: some View { OrbitRootHost(orbit) }
}

struct HomeView: View {
    @Environment(\.orbit) private var orbit

    var body: some View {
        Button("Open detail") {
            orbit.push(DetailRoute(title: "Detail"))
        }
        .navigationTitle("Home")
    }
}
```

The factory receives the route's payload. It is also the place to provide
the destination's ViewModel or other dependencies.

For launch routing, `OrbitRootHost(orbit) { SplashView() }` displays a
placeholder until a root has been selected. The placeholder can use the
environment router to call `setRoot` when its launch work completes.

## Tabs

Use `OrbitTabView` to declare each tab's content and label. Orbit creates a
separate navigation stack for each tab and retains its history when switching.

```swift
nonisolated final class TabsRoute: OrbitRoute {}
nonisolated final class HomeTab: OrbitTab {}
nonisolated final class TasksTab: OrbitTab {}

@MainActor
func configureTabs(in orbit: Orbit) {
    orbit.register(TabsRoute.self) { _ in
        OrbitTabView(tabBarVisibility: .hiddenOnPush) {
            OrbitTabItem(HomeTab()) {
                Text("Home")
            } label: {
                Label("Home", systemImage: "house")
            }

            OrbitTabItem(TasksTab()) {
                Text("Tasks")
            } label: {
                Label("Tasks", systemImage: "checklist")
            }
        }
    }
    orbit.setRoot(TabsRoute())
}
```

Tab selection uses the tab's type. Calling `selectTab` preserves that tab's
stack; pass `replacingPath` to select it with a different history. An empty
replacement path opens the tab's root screen.

The default tab-bar policy is `.automatic`. Choose `.hiddenOnPush` to hide it
while a tab has pushed destinations, or `.visible` to keep it visible.

Tab flows can be roots or modal destinations. A modal with its own tabs has
independent selection and history.

## Navigation

Screens access an `OrbitRouter` through `@Environment(\.orbit)`:

| Command | Behavior |
|---|---|
| `push(route)` | Adds a destination to the screen's stack. |
| `pop()` / `popToRoot()` | Returns to the previous destination or stack root. |
| `popTo(RouteType.self)` / `popTo(route)` | Returns to a matching pushed type or instance. |
| `present(route, style:)` | Starts a sheet or full-screen flow with its own navigation state. |
| `dismiss()` | Closes the screen's modal flow. |
| `setRoot(route)` | Replaces the window's root while preserving active modals. |
| `selectTab(tab, replacingPath:)` | Selects a tab in the nearest tab flow, optionally replacing its stack. |

The scene-owned `Orbit` also provides `setRoot`, `present`, `selectTab`, and
`dismissAll`. Its tab selection targets the root's tabs, which is useful when
applying a resolved deep link from a service.

Commands run on the main actor. A `Bool` result reports whether the state
request was accepted; SwiftUI performs the visual transition afterward.

## Styling tab flows

Normal modifier chains, such as `.padding()` and `.preferredColorScheme()`,
preserve the tab flow. For type erasure or a custom container, use `wrapped`
to retain the original declaration alongside the decorated view:

```swift
@MainActor
func tabPanel(_ tabs: OrbitTabView) -> some View {
    tabs.wrapped { content in
        AnyView(Group { content }.padding())
    }
}
```

Reusable wrappers can also conform to `OrbitTabFlow`. The usage guide covers
[tab decoration](https://stlarner.github.io/Orbit/api/documentation/orbit/usageguide#Tab-decoration),
modal ownership, event delivery, and asynchronous navigation.
